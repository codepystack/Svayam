# Svayam

A minimalistic personal website to showcase my work, projects, and thinking.

## Pages

- **Home** — About, photo, social links, and contact
- **Now** — What I'm currently working on
- **Ideas** — Project ideas I want to build
- **Uses** — Tools, setup, and software I use
- **Notes** — Short thoughts and technical notes
- **Experiments** — Small side projects and prototypes

## Run locally

Open `index.html` in any browser — no build step required.
