# Svayam

A minimalistic personal website to showcase my work, projects, and thinking.

## Pages

- **Home** — About, photo, social links, and contact
- **Now** — What I'm currently working on
- **Ideas** — Project ideas I want to build
- **Uses** — Tools, setup, and software I use
- **Notes** — Short thoughts and technical notes
- **Experiments** — Small side projects and prototypes

## Hosting

This site is deployed to **GitHub Pages** via the workflow in `.github/workflows/deploy.yml`.

### Custom domain

To use a custom domain, add a `CNAME` file to the repository root containing your domain:

```
yourdomain.com
```

Then configure your DNS provider to point to GitHub Pages. See [GitHub's custom domain docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site) for details.

## Run locally

Open `index.html` in any browser — no build step required.
